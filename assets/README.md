# assets

- `kuma.png` … Instagram画像に毎回入れる固定のクマ（サングラス・白衣・紺色スクラブ・コーヒーを持った茶色いクマ）のアイコン。
  正方形の画像を置くと、中央を丸く切り抜いて使います。丸い外側は透明にしてあります（元画像は1254×1254、640×640に縮小）。

- `kuma-reference/collage-15scenes-2026-11-14.png` … サングラスくまの正式なデザインの参考資料（社長が2026-11-14に指定。15場面のコラージュ・1536×1024）。
  画像生成の**マスター画像ではない**（1枚に複数の場面があり、解像度も足りないため）。キャラクターの基準を確かめるときに見る。
  画像の中の衣類・帽子にある他社のロゴは、生成する画像では描かない。
- `kuma-master/` … 画像生成で参考に渡す、単独の高品質なマスター画像（2026-11-14 取り込み：`full-front.png` 正面・全身 1141×1378、`upper-front.png` 正面・上半身 1312×1199）。
  取り込みは `node scripts/kuma-master-add.mjs`、一覧は `lib/kuma-master-manifest.js`（大きさ・指紋 sha256）。社長の承認はアプリの「広報」の欄で行い、サーバーに記録する。
  承認されたマスターが無い間・承認後に画像が差し替えられたときは、表紙画像を作らない。黒いパーカーは撮影用の衣装（固定しない）。
