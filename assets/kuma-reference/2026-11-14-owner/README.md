# 商品紹介画像の制作基準（社長の決定 2026-11-14）

いちばん大事なこと：**サングラスくまが、紹介する商品を自然に使っていること**。広告のポーズではなく、日常の一瞬に見えること。

## 1. 使用シーンを商品ごとに企画する
- 商品の実際の使い方（商品ページで確かめた用途）から、自然な日常の場面を考える
  - 例：加湿器＝机で使いながらくつろぐ／香水＝香りを試す／スマホスタンド＝スマホを置いて画面を見ながら操作する
- 構図・カメラの角度・くまの位置は固定しない。その使い方がいちばん自然に伝わるものをAIが判断する

## 2. 合格の条件（すべて満たすこと）
1. 商品が画面の中で大きく、何の商品か一目で分かる
2. くまが商品を実際に使っている、または自然に関わっている（立っているだけ・横でポーズは不可）
3. 立体感のある日常の場面・暖かい光・奥行き（参考：加湿器と香水の表紙、15場面のコラージュ、direction の画像）
4. くまの外見が正式マスター2枚と同じ（キャメル色のふわふわ・大きな黒いサングラス・丸い顔・短い手足・3Dぬいぐるみの質感）。衣装は場面に合わせて変えてよい
5. 商品の形・色が実物と大きく違わない
6. 商品以外に不要なロゴ・文字が無い（黒いマグカップの白いメガネのマークは、ブランドの目印として可）
7. タイトルを重ねる余白がある（タイトルは生成後にプログラムで重ねる）

## 3. 不採用にするもの
- 商品の形・使い方に明らかな矛盾がある（例：くまから画面が見えない向きでスマホを操作している、部品の組み立て方が実物と違う）
- 商品が写っていない・小さすぎて分からない
- 文字中心のテンプレート画像
- 画像が用意できないときに、代わりのもので埋めた投稿（その場合は作らずに報告する）

## 4. 「完成」の数え方
- ファイルがそろったことでは完成としない。上の条件をすべて満たし、さらに社長が採用したものだけを完成として数える
