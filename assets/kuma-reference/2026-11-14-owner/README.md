## 表紙の共通点（実際の画像から）
1. 商品が主役：手前（画面の下3分の1）に、実物どおりの商品が大きく、くっきり並ぶ（加湿器3色・香水3本）。何の商品か一目で分かる
2. くまが商品に関わっている：商品の奥でほおづえをついて眺める（加湿器）、試香紙を鼻に当てる（香水）。立っているだけではない
3. 場面：木の机・本棚・観葉植物・デスクライト。夕方の斜めの暖かい光、背景はぼかす。加湿器は湯気まで描く
4. 文字：左上の暗めの部分に白い文字。手書き風の一言（「デスクが、ちょっと好きになる。」「今日は、どれにしよう…」）→ 明朝体の大きな見出し（「卓上加湿器」「大人の香水セレクション」）→ ベージュの帯の小見出し（「デスクの雰囲気づくりに」「メンズにおすすめ」）→ 必要なら数字（「3選」）
5. ブランドの目印：机の上の黒いマグカップに白いメガネのマーク
6. くまの衣装：黒いパーカー（両方の表紙）

## 場面のコラージュの共通点
- くまが毎回、何かをしている（飲む・読む・料理する・運転する・買い物・キャンプ）。物を手に持つか操作している
- 暖かい光（夕方・ランプ・焚き火）、浅いピント、生活感のある実在の場所
- 衣装は場面ごとに変わる（パーカー・フリース・エプロン・ジャケット・ニット帽）。下はほぼ同じグレーのスウェットと白いスニーカー
- 注意：服・帽子・小物に他社のロゴが多く写っている（Champion・Nike・The North Face・Lacoste・Patagonia・NY・Apple など）。新しく作る画像では描かない（商標の扱いが未確認のため）
