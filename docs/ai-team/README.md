# AI経営チーム（最小構成）

進め方：調査・議論・企画立案はAI社員が自分たちで進め、社長の承認が必要なこと（費用・外部への投稿や連絡・ブランドの大きな変更・既存機能の削除）だけを最後にまとめて出す（docs/ai-team/company.md）。

「眼科医くま」の Instagram・楽天ROOM 運用のための、Claude Code のサブエージェント5人と、まとめ役の CEO補佐（メインの Claude）の構成。
新しい有料API・外部DB・定期実行サービスは使わない。Claude Code の中だけで動く。

## メンバー（.claude/agents/）
| ファイル | 役職 | 使える道具 | 主な仕事 |
|---|---|---|---|
| marketing-lead.md | マーケティング責任者 | 読む・検索・Web検索 | フォロワー0からの集客施策 |
| competitor-researcher.md | 競合調査担当 | 読む・検索・Web検索・Web取得 | 実在の競合・公式情報を出典つきで調べる |
| planning-lead.md | 企画責任者 | 読む・検索・Web検索 | 調査をもとに差別化した企画と、1週間の企画カレンダー |
| audit-lead.md | 監査責任者 | 読む・検索・Web検索・Web取得 | 根拠・規約・費用・負荷・期待値を検証し、反対意見を出す |
| product-buyer.md | 商品バイヤー（5人目） | 読む・検索・Web検索・Web取得 | ランキング上位の定番ではない「こんな商品があったのか！」を発掘し、企画担当に渡す（docs/ai-team/buyer.md） |

- 全員の共通の前提：`docs/ai-team/company.md`
- 全員、ファイルを書き換える道具・コマンドを実行する道具を持たない（読む・調べるだけ）。
- SNSへの投稿・広告出稿・DMは誰も実行できない。必ず社長が承認して、自分で行う。

## 会議の進め方（CEO補佐がやること）
1. 第1ラウンド（同時・独立）：マーケティング責任者と競合調査担当に、同じテーマを別々に渡す（互いの結果は見せない）。
2. 第2ラウンド：企画責任者に調査結果だけを渡す（マーケの案は見せない＝似た案に引っぱられないように）。
3. 第3ラウンド：監査責任者に全員の報告を渡し、施策ごとの判定と反対意見を出させる。
4. まとめ：CEO補佐が、施策の候補・反対意見・優先順位・今週の行動計画・判定指標にまとめて社長に提案する。
5. 記録：`docs/ai-team/meetings/日付-テーマ/` に、00-summary.md（まとめ）と各担当の報告を残す。

## 呼び出し方
- Claude Code で「AI経営チームで会議して：（テーマ）」と頼む。
- 各担当を個別に呼ぶときは、Agent のエージェント名に marketing-lead / competitor-researcher / planning-lead / audit-lead を指定する。
  - `.claude/agents/` は、セッションを開き直すと読み込まれる。
  - 初回の会議は、この定義ファイルを読ませた汎用のサブエージェントで行った。

## 制約（いまの最小構成でできないこと）
- Instagram・楽天のリアルタイムの数字（インサイト）は見られない → 社長がインサイトの数字を伝える（将来、Instagram Graph API のインサイトを読む機能を、社長の承認のうえで足すことを検討）。
- この環境のネットワーク設定では、help.instagram.com・creators.instagram.com・room.rakuten.co.jp・affiliate.rakuten.co.jp・mhlw.go.jp などの原文を開けない（検索の要約と報道で代用し、「未確認」と明記している）。原文を読むには、セッションのネットワーク設定でこれらのドメインを許可する。
- 定期的な会議（毎週の振り返りなど）は、自動では動かない（定期実行サービスを使わないため）。社長が頼んだときに行う。
