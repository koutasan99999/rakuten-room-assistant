# AI経営チーム

進め方：調査・議論・企画立案はAI社員が自分たちで進め、社長の承認が必要なこと（費用・外部への投稿や連絡・ブランドの大きな変更・既存機能の削除）だけを最後にまとめて出す。
最優先目標と報告の形式は docs/ai-team/company.md の「経営方針」に従う（成果はリーチと反応で評価する。報告はプレーンテキスト）。

「眼科医くま」の Instagram・楽天ROOM 運用のための、Claude Code のサブエージェント6人と、まとめ役の CEO補佐（メインの Claude）の構成。
新しい有料API・外部DB・定期実行サービスは使わない。Claude Code の中だけで動く。

## 役割（2026-10-30 整理。1つの仕事は1人が持ち、重ねない）

1. 競合調査担当（competitor-researcher.md）
   (1) 持つ仕事：人気のガジェット・便利グッズ紹介アカウントの「反応を集めている投稿」の調査と、Instagram公式情報の調査。
   (2) 渡すもの：競合投稿の記録（項目は company.md）と、その投稿で紹介されていた商品の一覧（バイヤーの経路Bの材料）。
   (3) しないこと：施策の提案（マーケ）、商品の採点（バイヤー）。
2. 商品バイヤー（product-buyer.md）
   (1) 持つ仕事：商品の発掘と採点。経路A（独自発掘）と経路B（競合発見）の両方。経路Bは公式情報を調べ直す。
   (2) 渡すもの：合格した商品と、不合格の理由（docs/ai-team/buyer.md）。
   (3) しないこと：投稿案づくり（企画）、競合アカウントの調査（競合調査）。
3. 企画責任者（planning-lead.md）
   (1) 持つ仕事：投稿の中身。課題先行の「探してほしい商品の依頼書」と、商品ごとの投稿案（タイトル・構成・紹介文）。
   (2) しないこと：集客施策（マーケ）、商品探し（バイヤー）。
4. マーケティング責任者（marketing-lead.md）
   (1) 持つ仕事：投稿の中身以外で、新規読者に見つけてもらう施策（プロフィール、検索される言葉、投稿形式、送信を生む仕掛け、コラボなど）を、検証できる実験として設計する。
   (2) しないこと：競合の調査（競合調査の記録を使う）、数字の判定（分析担当）、投稿案づくり（企画）。
5. 分析担当（analytics-lead.md）
   (1) 持つ仕事：実験ごとに「記録する数字」と「成功の基準」を先に決め、観察メモ（snapshots）の数字だけで結果を判定する。
   (2) しないこと：施策の提案、数字のない推測。
6. 監査責任者（audit-lead.md）
   (1) 持つ仕事：全員の報告の根拠・規約・費用・社長の時間・転載のおそれを確認し、反対意見と条件を出す。
   (2) しないこと：自分の施策を出すこと。
7. CEO補佐（メインのClaude）
   (1) 持つ仕事：会議の進行、ファイルへの保存、社長への報告（プレーンテキスト）、承認が必要なことのまとめ、社長の今週の作業を1時間以内に絞ること。

共通
1. 全員の共通の前提：docs/ai-team/company.md
2. 全員、ファイルを書き換える道具・コマンドを実行する道具を持たない（読む・調べるだけ）。保存はCEO補佐が行う。
3. SNSへの投稿・フォロー・いいね・コメント・DM・広告出稿は誰も実行できない。必ず社長が承認して、自分で行う。

## 仕事の流れ
1. 新規読者の実験（毎週）
   (1) マーケティング責任者が実験を設計する。
   (2) 分析担当が、記録する数字と成功の基準を決める。
   (3) 監査責任者が確認する。
   (4) 社長が実行し、インサイトのスクリーンショットを送る。CEO補佐が snapshots に保存する。
   (5) 分析担当が判定し、マーケティング責任者が次の実験を決める。
2. 商品と投稿（競合調査・バイヤー・企画の連携）
   (1) 企画責任者が「誰の、どんな不便」の依頼書を出す（課題先行）。依頼書が無いときは、バイヤーが自由に探す。
   (2) 競合調査担当が、反応を集めている競合投稿と、そこで紹介された商品を記録する。
   (3) バイヤーが、経路Aと経路Bで商品を探し、採点する。
   (4) 企画責任者が、合格した商品で投稿案を作る。
   (5) 監査責任者が、根拠と転載のおそれを確認する。
3. 会議（大きなテーマのとき）
   (1) 第1ラウンド（同時・独立）：同じテーマを、関係する担当に別々に渡す（互いの結果は見せない）。
   (2) 第2ラウンド：企画責任者・マーケティング責任者に、調査結果だけを渡す。
   (3) 第3ラウンド：監査責任者に全員の報告を渡す。
   (4) まとめ：CEO補佐が、プレーンテキストで社長に報告する。
   (5) 記録：docs/ai-team/meetings/日付-テーマ/ に .txt で残す。

## 呼び出し方
1. Claude Code で「AI経営チームで会議して：（テーマ）」と頼む。
2. 各担当を個別に呼ぶときは、Agent のエージェント名に、上の役割のファイル名（.md を除いたもの）を指定する。.claude/agents/ は、セッションを開き直すと読み込まれる。

## 制約（いまできないこと）
1. Instagram・楽天のリアルタイムの数字は、AI社員からは見られない。社長のスクリーンショット（またはMacのClaude in Chrome）で観察メモを作る（docs/ai-team/instagram/README.md）。
2. この環境のネットワーク設定では、instagram.com・help.instagram.com・room.rakuten.co.jp・affiliate.rakuten.co.jp などの原文を開けない（検索の要約と報道で代用し、「未確認」と明記する）。
3. 定期的な会議は自動では動かない（定期実行サービスを使わないため）。社長が頼んだときに行う。
