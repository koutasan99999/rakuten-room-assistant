# 監査責任者（audit-lead）の判定 — バイヤー発掘便 第1便（Web調査便）

## 商品ごとの判定
| 商品 | 判定 | 主な指摘と対応 |
|---|---|---|
| trapo | 見送り | 「特許製品」は出典にない（削除済み）。Makuakeの限定販売で、受付状況は未確認。楽天にないのでROOMにも載せられない。受付中と確認できるまで投稿しない（「投稿にする」は押せない） |
| CHARMY クリスタ 予洗い専用泡スプレー | 条件つき可 | 「日本初」には「ライオン調べ・Mintelデータ、2025年12月時点」を必ず添える（添え済み）。ひとことの「吹きかけるだけで済む」は言い過ぎなので直した |
| サンコー HDHW26C | 条件つき可 | ひとことが使ったように読めるので直した。9,980円は発売時の報道値と明記し、最新は商品ページで確認と添えた。連続10分以内の注意書きは残す |
| マーナ スプーンマッシャー | 条件つき可 | この商品のグッドデザイン賞の受賞は確認できていないので、タイトル・スライド・理由・紹介文から外した。楽天の個別の商品ページは、ROOMに登録する前に確認する |
| サンワ スリムタップ | 可 | ひとことを「ぶつかりにくい」に直した |

- 全商品共通：専門医・目の健康・医療の表現はない。PR表記は表紙かキャプションの冒頭に入れる。

## 機能設計への指摘と対応
1. **スコアの比べ方**：Web調査便のスコアはAIの評価だけ。アプリの便とは比べられない → 画面に「AIの評価だけで出した点数（アプリの便の点数とは比べられません）」と表示した。
2. **知名度の目安**：「新製品」であることと「知られていない」ことは別 → 「新製品（発売日）。知名度は未確認」と書くようにした。
3. **評価がWeb調査便に届かない**：評価はiPhoneの中だけにある → 画面に「評価を書き出す」を追加した。社長が Claude Code に貼れば、次のWeb調査便で避ける商品として使う。

## 社長の承認が必要なこと
- 4件（CHARMY・サンコー・マーナ・サンワ）をInstagramに投稿すること、楽天ROOMに登録すること（外部への投稿）。
- trapoの受付状況を、BeauBelle・Makuakeに問い合わせる場合（外部への連絡）。
- 費用・ブランドの変更・機能の削除にあたるものはない。
