# Mac の Claude in Chrome で @ganka_kuma_ を見て、観察メモを作る（初心者向け）

所要時間：最初だけ15〜20分。2回目からは5分ほど。費用：0円（今のClaudeのプランで使える範囲。Claude in Chrome が使えないプランのときは、画面に案内が出る）。
AIは「見る」だけ。投稿・フォロー・いいね・コメント・DMは絶対にさせない（下の「お願い文」にも書いてある）。

## 準備（最初の1回だけ）
1. Mac で Google Chrome を開く（Safari では使えない）。
2. Chrome で「Claude in Chrome」と検索し、Anthropic公式の拡張機能のページ（Chromeウェブストア）から「Chromeに追加」を押す。
3. Chrome の右上のパズルのマーク → Claude の横のピンを押して、ボタンを常に出しておく。
4. Claude のボタンを押し、iPhoneでClaudeに使っているのと同じアカウントでログインする。
5. 同じChromeで https://www.instagram.com を開き、@ganka_kuma_ でログインしておく。

## 毎回やること（観察メモを作る）
1. Chrome で https://www.instagram.com/ganka_kuma_/ を開く。
2. Claude のボタンを押して、横に出た画面に、下の「お願い文」をそのまま貼り付けて送る。
3. Claude がサイトを読む許可を求めてきたら、「このサイトで許可」を選ぶ（instagram.com だけ）。
4. 返ってきた観察メモを全部コピーする。
5. iPhone の Claude Code のこの会話に貼り付けて、「観察メモを保存して分析して」と送る。
   - CEO補佐が `docs/ai-team/instagram/snapshots/日付.md` に保存し、分析担当・マーケティング責任者が分析する。

## インサイトがWebで見られなかったとき
iPhone の Instagram アプリで、プロフィール → 「プロフェッショナルダッシュボード」（または各投稿の「インサイトを見る」）を開き、スクリーンショットを撮って、この会話に画像として送ってください。数字は画像から読み取って、観察メモと同じ形式で保存します。

## 守ること
- AI社員がInstagramを見るのは、社長がChromeで開いて頼んだときだけ（自動で何度も見に行かない）。
- 操作（投稿・フォロー・いいね・コメント・DM）は社長だけが行う。
- 他人のアカウントの情報は、公開されている範囲を社長が見て伝えたものだけを使う。
