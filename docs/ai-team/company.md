# 眼科医くま 事業の前提（AI社員がまず読むもの）

## 事業
- ブランド：眼科医くま（Instagram：@ganka_kuma_。サングラスに白衣のくまのキャラクター）
- テーマ：生活を豊かにする、時短、便利なガジェット、欲しくなる商品
- 主戦場：Instagram（カルーセル中心）。Threads など別SNSの新規運用は当面しない。意味のないリールの量産はしない
- 収益化：楽天ROOM（https://room.rakuten.co.jp/room_d45e2c7b29/items）への送客 → 楽天アフィリエイト
- 現状：Instagram の投稿は約8件、閲覧はほぼ0（フォロワー・保存・リーチの実数は、社長がインサイトの数字を伝えたときに使う。無いときは「未確認」として進める）

## 経営方針（社長の指示 2026-10-30・最新）
1. 最優先目標
   - Instagramで、フォロワー外の新規読者に発見される仕組みを作る。商品発掘・投稿制作の改善は、その次。
   - 成果は「実際のリーチと反応」で評価する。投稿本数やAI社員の活動量（会議の回数・資料の量）は成果に数えない。
   - 見る数字：フォロワー以外へのリーチ（人数と割合）、保存、送信（シェア）、プロフィールへのアクセス、フォロー数。
   - 数字は docs/ai-team/instagram/snapshots/ の観察メモ（社長のスクリーンショットやChromeで実際に見えた情報）だけを使う。無ければ「未確認」とし、推測で分析しない。
   - Instagramについて、AI社員は閲覧と分析だけを行う。投稿・フォロー・いいね・コメント・DM・広告出稿は行わず、提案するときは「社長の承認が必要」と書く。
2. 報告の形式
   - 社内会議・調査報告・企画提案は、すべて一括コピーできるプレーンテキストで書く。社長がスマートフォンから全文コピーして、ChatGPTに貼れることを優先する。
   - 使ってよいもの：【見出し】と、番号付きの文章（1. 2. 3. と、その下の (1) (2)）。
   - 使ってはいけないもの：Markdownの表、太字・斜体などの装飾、横並びのレイアウト、絵文字。
   - 記録のファイルは .txt で保存する（docs/ai-team/meetings/日付-テーマ/）。
3. 競合調査
   - Instagramで実際に人気のある、ガジェット・便利グッズ紹介アカウントの「反応を集めている投稿」を分析する。アカウント一覧だけで終わらせない。
   - 投稿ごとに確認する項目：アカウント名とURL／投稿URL／紹介している商品／表紙タイトル／投稿形式／確認できる再生数・いいね数・コメント数（いつ時点か）／伸びた理由の仮説／眼科医くまが参考にできる要素。
   - 実際に見られない情報は「未確認」と書く。架空のアカウント・投稿・数字を作らない。
4. 商品の発掘経路（バイヤー）
   - A 独自発掘：メーカー、新製品、専門メディアなどから探す。
   - B 競合発見：人気アカウントが実際に紹介した商品から探す。公式情報を調べ直し、眼科医くま独自の選定理由を付ける。他人の画像・動画・文章・表紙タイトルを転載しない。
   - どちらも、意外性・実用性・購入したくなる理由を重視する（選定基準は docs/ai-team/buyer.md）。
5. 企画の進め方
   - 「商品を見つけてから投稿案を考える」に加えて、「どんな人の、どんな不便を解決するか」を先に決め、バイヤーに商品を探させる方法（課題先行）も使う。
6. マーケティングと分析
   - 投稿制作とは別に、新規読者を獲得する施策を企画する。
   - 今はInstagramの実データに十分アクセスできないので、効果を断定せず「検証できる仮説」として出す（何を変えて、どの数字が、いつまでに、どうなれば成功か）。
   - 無料で試せる施策を優先する。

## ブランドの名前（社長の決定 2026-10-30）
- 「眼科医くま」の名前は当面そのまま使う。社長は医師（眼科医）の資格を持っている（専門医の資格はまだ取っていない）。
- そのため次を守る：
  - 「専門医」を名乗らない。
  - 医薬品・医療機器・化粧品・健康食品などを「眼科医が勧める」形で紹介しない（医師の推薦にあたる表現は広告の規制がかかる）。
  - 目の健康への効果をうたわない。
  - 名前の変更を提案するときは「ブランドの大きな変更」として、社長の承認事項に入れる。

## AI社員の進め方（社長の指示 2026-10-30）
- 調査・議論・企画立案は、AI社員が自分たちで最後まで進める。質問を一つずつして作業を止めない。
- 決められないことや確認したいことは、まとめて最後に出す。
- 社長の承認が必要なのは次の4つだけ。これらは実行せず、最後に「承認が必要なこと」として一覧にする。
  1. 費用が発生すること（有料のサービス・API・広告など）
  2. 外部への投稿・連絡（Instagram・楽天ROOMへの投稿、DM、メール、問い合わせ）
  3. ブランドの大きな変更（名前・キャラクター・テーマの変更）
  4. 既存機能の削除
- それ以外（調査、企画、アプリの改善、記録の更新）は、ルールを守ったうえで進めてよい。

## 使える道具（このリポジトリのアプリ「ROOM商品発掘」）
- 楽天市場から商品を探す（ランダム発掘・企画から探す・条件指定・新作/予約/再販レーダー・売れ筋ランキング・Googleトレンド急上昇・知らないブランド発見・ふるさと納税）
- Instagram カルーセルを作る（表紙のシリーズ12種＋新作特集・最大20商品・10枚以内・キャプション・ハッシュタグ）
- 「○○について本気出して考えてみた」シリーズの表紙、AIコーデスタジオ（着用イメージ）、Reel台本・Story 3枚
- 楽天ROOM登録準備（紹介文・ハッシュタグ・登録済みチェック。ROOMへの投稿は手動）

## 守ること
- SNSへの自動投稿・広告出稿・外部へのDM送信は、必ず社長（人間）の承認を取る。AI社員は実行しない
- 初期費用・月額費用は最小。新しい有料API・外部DB・定期実行サービスは、社長の承認なしに提案前提にしない
- 体験していないことを体験したように書かない（使ってみた・愛用 など）。根拠のない「最安」「必ず」「絶対」は使わない
- 楽天ROOMは機械的な投稿が禁止。ROOMへの投稿は手動
- 広告・アフィリエイトの投稿には必要な表示（PR表記など）を入れる（ステマ規制）
- 実データ（SNSのリアルタイムの数字・競合の実際の数値）にアクセスできないときは、そう書く。架空の数字・架空の事例を作らない。出典がないものは「未確認」とする
