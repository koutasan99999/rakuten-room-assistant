# 販売戦略：誰が・なぜ・私たちの紹介から買うのか（2026-11-14）

状態：設計と実装（ブランチ claude/buyer-stock・PR #97）。本番は未反映。
目標：月3万円の安定報酬。成果の指標は、いいね・フォロワーではなく「クリック・購入・報酬」。

## 1. お客様と購入動機（仮説）
- お客様：忙しい社会人。提供する価値は「買い物の失敗を減らす商品選び」
- 購入動機（3つを比べて検証する）：
  | id | 動機 | 合う発掘の切り口 | 投稿の組み立て | ハイライト |
  |---|---|---|---|---|
  | fix | 日常の不便を解消したい | 定番・独自性・季節 | 困りごと → この商品で何が変わるか（事実だけ）→ 注意点 | 日常の不便 |
  | gift | 失敗しないプレゼントを選びたい | ギフト・季節・定番 | 贈る相手と場面 → 予算 → 外しにくい理由 → 確認点 | プレゼント |
  | compare | 新作・定番・型落ちを比べて納得して買いたい | 新作表記・型落ち・セール・定番 | 比べる軸 → どれが誰に合うか → 選び方のまとめ | 比べて選ぶ |
- コード：`lib/buyer-angles.js` の `MOTIVES`

## 2. バイヤーAIが必ず考えること（候補ごとに記録・コードで確認）
- 誰が買うか（whoBuys）／何に困っているか（problem）／なぜ今買う価値があるか（whyNow）
- 競合と比べて何が優れているか（vsOthers）：同じ検索結果のほかの商品の番号（R…）つき。両方の商品データにある事実だけ
- 価格・購入先に納得できる理由（priceReason）：価格・送料・ショップなど楽天のデータから
- どんな投稿なら購入を検討してもらえるか（postIdea）／紹介の根拠（evidence：楽天の商品データの引用・レビュー、確認日つき）
- どれかが欠ける、または比較の相手の番号が無い候補は、コードの確認（brief）で不合格。監査AIにもすべて見せる
- 情報源のない「SNSで話題・テレビで紹介・芸能人が使用」などは不合格（claims）。楽天ROOMの報酬対象（アフィリエイトの料率）も確認（room）

## 3. 制作ライン
- 企画の購入動機は、直近の投稿セットで少ない動機から選ぶ（3つを同じくらい作って比べるため）。その動機の合格候補を優先して渡す
- 企画担当AIに、購入動機・投稿の組み立て・商品ごとの「誰が・困りごと・なぜ今・競合との比較・価格の理由」を渡す
- 投稿セットに `motive` と `funnel`（販売導線）を残す。画面の投稿セットのカードに表示
- 表紙画像は「AI生成イメージ」と必ず表記。本文・紹介文に「使ってみた」などの体験の表現は書かない（AIの画像を実際の使用体験と偽らない）

## 4. 販売導線（購入までの操作を減らす）
- 前提：フィードの本文のURLは押せない（Instagramの仕様）。プロフィールのリンク→楽天ROOMのトップ→商品を探す、は操作が多い
- 案（投稿は社長が手で行う・自動投稿はしない）：
  1. 商品ごとにストーリーズを1枚作り、リンクスタンプで商品ページへ（1タップ）
  2. そのストーリーズを、購入動機ごとのハイライト（「日常の不便」「プレゼント」「比べて選ぶ」）に残す（投稿が流れても辿れる）
  3. フィードの本文は「ストーリーズのハイライト『◯◯』のリンクから1回で開けます」と案内（コードが本文の最後に付ける）
  4. プロフィールのリンクは楽天ROOMのトップ（今までどおり）
- リンク先：社長が楽天ROOMに登録した商品ページを推奨（ROOM経由の購入も報酬の対象）。登録前は楽天の商品ページのURLを仮に入れてある
- 【要確認】リンクスタンプを使えるアカウントの条件（Instagramの公式）／楽天アフィリエイトのリンクをInstagramに直接貼ってよいか（楽天アフィリエイトの規約）。この作業環境からは公式ページを確認できず、販促会社の解説記事しか見つからなかった

## 5. 検証（3つの購入動機を比べる）
- 各動機の投稿セットを、社長が採用して投稿する（同じ時期に1件ずつ以上）
- 測る数字（取得できないものは「未取得」のまま。推測で埋めない）：
  | 数字 | 取り方 |
  |---|---|
  | 閲覧・リーチ・プロフィールへのアクセス | Instagramのインサイト（公式APIの鍵があれば自動、なければ手入力） |
  | ストーリーズのリンクのタップ | ストーリーズのインサイトを見て手入力（新しく欄を追加） |
  | プロフィールのリンクのタップ | 手入力（アカウント全体はAPIで取れる） |
  | ROOMへの流入・売上・報酬 | 楽天アフィリエイトの報告から手入力（報酬の欄を新しく追加）。楽天にはAPIが無い |
- 比べる場所：経営報告の「成果」欄に、購入動機ごとの投稿セット数・採用数・投稿数・閲覧・リンクのタップ・ROOMへの流入・売上・報酬を表示（`js/work.js`）
- 判断：一定期間（例：2週間）の報酬とクリックで、動機ごとに続ける・やめるを決める。数が少ないうちは結論を出さない
